这个文件夹是 1.3.1 及以前的照片位置，**新版本不再读取它**。

从 1.4.0 起，照片存放在用户数据目录：

```text
$DSH_HOME/dsh-snap-line/photos/        # 默认 ~/.dsh/dsh-snap-line/photos/
├── <原图>                              # 原样保存的图片文件
├── .display/                           # 晾衣绳用的显示版，删掉可以重建
└── .order.json                         # 照片顺序，前 6 张上绳
```

添加照片的推荐方式是在 Harness 侧栏打开 **插件 → 已安装插件 → dsh-snap-line**，用详情页里的照片管理器添加（多选或拖入）、删除和排序（拖动或 ↑/↓）。手工放置仍然有效：把图片放进上面的照片目录，5 秒内会自动上绳。

旧版本留在这个文件夹里的个人照片不会被自动迁移，请在新版详情页里重新添加；这些文件不在 Git 里，可以放心留在本地或自行删除。
